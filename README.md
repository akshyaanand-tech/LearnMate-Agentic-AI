# LearnMate - Agentic AI for Personalized Course Pathways

## Problem Statement

Students often struggle to identify the right learning path that aligns with their interests and long-term career goals due to the overwhelming number of online courses and lack of personalized guidance.

## Solution

LearnMate is an Agentic AI-powered learning assistant that:

- Understands student interests
- Assesses current skill levels
- Identifies skill gaps
- Generates personalized learning roadmaps
- Recommends courses, certifications, and projects
- Provides career-oriented learning guidance

## Technologies Used

- LangFlow
- IBM watsonx.ai
- IBM Granite-4.0-8B-Instruct
- Retrieval-Augmented Generation (RAG)
- Vector Database (FAISS/Chroma)

## Agent Workflow

1. Profile Analysis Agent
2. Skill Assessment Agent
3. Roadmap Generation Agent
4. Learning Resource Agent

## Architecture

The system uses a Multi-Agent AI architecture integrated with IBM Granite models to generate personalized learning pathways.
